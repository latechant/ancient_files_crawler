# 唐袁滋《云南记》佚文辑存
# 辑录日期: 2026-10-10
# 说明: 袁滋《云南记》五卷，唐贞元十年(794)袁滋奉使南诏(册封异牟寻)后所撰，
#       原书久佚，今无传本，亦无武英殿/四库等刊本。以下为《太平御览》所引
#       题作《雲南記》之佚文，逐条注明卷次、部类。
# 归属说明: 据屈直敏《袁滋〈云南记〉考略》(《中国边疆史地研究》2009年)，
#       群书所引题作《雲南記》之佚文共24条，其中引文含"韦齐休"姓名者疑别有所属，
#       其余多可定为袁滋《云南记》佚文。本辑中卷0919、卷0974二条含"韦齐休"，
#       姑存备考，归属存疑(见各条下注)。
# 底本: 维基文库《太平御覽》(据《四部叢刊三編》本、《欽定四庫全書》本)。
# 检索范围: 《太平御覽》全书题作"雲南記曰/雲南記"之条目。
# 注意: 本辑仅为佚文，非完整正文；不得以樊绰《蛮书》充作袁滋《云南记》。
# ============================================================================

【一】《太平御覽》卷八百三十九·百穀部三(稻)
《雲南記》曰：雅州榮經縣，土田歲輸稻米畝五斗。其穀精好，每一斗穀近得米一斗，炊之甚香滑，微似糯味。

【二】《太平御覽》卷九百一十九·羽族部六(鵝)
《雲南記》曰：韋齊休使雲南，屯城驛。西牆外有大池，斗門垂柳夾陰，池中鵝鴨甚眾。
〔按〕此條稱"韋齊休"，與韋齊休《雲南行記》相涉，歸屬存疑。

【三】《太平御覽》卷九百三十七·鱗介部九(嘉魚)
《雲南記》曰：雅州丙穴出嘉魚。所謂「嘉魚生於丙穴」。大抵雅州諸水多有嘉魚，似鯉而鱗細。成文黄河中魚味與此類也。

【四】《太平御覽》卷九百四十二·鱗介部十四(蛤)
《雲南記》曰：新安蠻婦人於耳上懸金環子，聯貫瑟瑟，帖於髻側。又繞腰以螺蛤，聯穿系之，謂為珂珮。

【五】《太平御覽》卷九百五十三·木部二(松)
《雲南記》曰：雲南有大松，子如新羅松子。

【六】《太平御覽》卷九百五十八·木部七(柘)
《雲南記》曰：會川室屋相次，皆是板及茅舍。滿川坡盡是花木，亦有赤柘。

【七】《太平御覽》卷九百六十二·竹部一(竹上)
《雲南記》曰：雲南有實心竹，文采班駮殊好，可為器物。其土以為槍簳交床。

【八】《太平御覽》卷九百六十六·果部三(橘)
《雲南記》曰：雲南出甘、橘、甘蔗、橙、柚、梨、蒲桃、桃李、梅杏，糖酪之類悉有。

【九】《太平御覽》卷九百七十一·果部八(檳榔)
《雲南記》曰：雲南有大腹檳榔，在枝朶上，色猶青。每一朶有三二百顆。又有剖之為四片者，以竹串穿之，陰乾，則可久停。其青者，亦剖之，以一片青葉及蛤粉卷和，嚼嚥其汁，即似減澁味。雲南每食訖，則下之。
又曰：雲南多生大腹檳榔，色青，猶在枝朶上，每朶數百顆。云是彌臣國來。
又曰：雲南有檳榔，花糝極美。

【十】《太平御覽》卷九百七十二·果部九(蒲萄)
《雲南記》曰：雲南多乾蒲萄。

【十一】《太平御覽》卷九百七十二·果部九(椰)
《雲南記》曰：南詔遣使致南國諸果，有椰子，狀如大牛心。破一重麄皮，刮盡又有一重硬殼。有小孔，以筋穿之，內有漿二合餘，味甘色白。
又曰：雲南多椰子，亦以蜜漬之為糝。

【十二】《太平御覽》卷九百七十三·果部十(餘甘子)
《雲南記》曰：瀘水南岸有餘甘子樹，子如彈丸許，色微黃，味酸苦，核有五稜。其樹枝如柘枝，葉如小夜合葉。

【十三】《太平御覽》卷九百七十四·果部十一(甘蔗)
《雲南記》曰：唐韋齊休聘雲南，會川都督劉寬使使致甘蔗。蔗節希似竹許，削去後亦有甜味。
〔按〕此條稱"韋齊休"，歸屬存疑。

【十四】《太平御覽》卷九百八十·菜茹部五
《雲南記》曰：嶲州界緣山野間有菜，大葉而麤莖，其根若大蘿蔔。土人蒸煑其根葉而食之，可以療飢，名之為諸侯菜。云武侯南征，用此菜子蒔於山中，以濟軍食。亦猶廣都縣山櫪林，謂之諸葛木也。

【十五】《太平御覽》卷九百九十五·百卉部二(藤)
《雲南記》曰：雲南出藤，其色如朱。小者以為馬策，大者可為柱杖。
