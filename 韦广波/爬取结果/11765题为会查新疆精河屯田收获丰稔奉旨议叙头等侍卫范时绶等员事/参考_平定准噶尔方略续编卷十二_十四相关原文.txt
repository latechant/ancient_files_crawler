# 一、《平定准噶尔方略续编》卷十二（乾隆二十六年六月壬申）
#     ——对应题名"奉旨议叙头等侍卫范时绶等员"
# ────────────────────────────────────────────────────────────────────────

乾隆二十六年六月壬申，命升叙解送羊只之参领范时绶等。上谕军机大臣曰：阿桂奏：范时绶由乌鲁木齐送羊一万三千只，全抵伊犁，办理妥协，又恳于办送回空驼只后，仍来伊犁效力等语。范时绶前因解送阿克苏羊只妥协，曾赏给参领职衔，此次更属奋勉，著加恩授为头等侍卫。乌鲁木齐亦有应办事务，仍在原处行走，不必又往伊犁。其在事官员著交部议叙，兵丁等赏给钱粮一月。

# 二、《平定准噶尔方略续编》卷十二（乾隆二十六年六月，庚申条）
#     ——对应题名"新疆精河（晶河）屯田"，范时绶总理玛纳斯、库尔喀喇乌苏、晶河三村事务
# ────────────────────────────────────────────────────────────────────────

议玛纳斯等处驻兵屯田事宜。
参赞大臣阿桂等奏言：查伊犁、乌鲁木齐之间，有玛纳斯、库尔喀喇乌苏、晶河三处，安设村庄，驻兵屯田，原以省额林哈毕尔噶一路台站挽运口粮之力。续经安泰等议，以一时难于尽举，暂停安设台站。玛纳斯距昌吉罗克伦不远，酌派屯田兵二百名；库尔喀喇乌苏、晶河距伊犁、乌鲁木齐俱远，每村派兵三百名，人各垦地十五亩。所需籽种、农具、驼只，由乌鲁木齐、巴里坤取用。其分驻马兵五百名，请以范时绶管辖。又查乌鲁木齐至伊犁，共安设二十一台，每台马兵五名，人给马二匹；绿旗兵十五名，人给马一匹，每台驼四只。晶河以西，归伊犁管辖，托多克以东，归乌鲁木齐管辖。奏入，得旨：军机大臣议奏。寻议：前据安泰等奏请玛纳斯等处驻防屯田，臣等议以设立三村庄，应分年酌办。今阿桂等议驻防兵丁较原奏一村五百名之数，三分减二，则一年内即可尽举，而屯兵八百名之收获，已足敷台站口粮之用，且距伊犁、乌鲁木齐不远，自可无虞。其令伊犁、乌鲁木齐就近分管，及派给马匹、籽种、农具，并将三村事务委范时绶总管，俱应如所奏办理。奏入，上从之。

# 三、《平定准噶尔方略续编》卷十四（乾隆二十六年 冬）"议玛纳斯等处屯田事宜"
#     ——以范时绶驻札三屯之中往来巡察
#     （以下为四库全书本原文，据维基文库《平定准噶尔方略（四库全书本）》续编卷十四；
#       四库本转录无新式标点，为存原貌不加句读）
# ────────────────────────────────────────────────────────────────────────

议玛纳斯等处屯田事宜
御前侍卫副都统安泰等奏言查原议玛纳斯库尔喀喇乌苏晶河三处屯田共需绿旗兵八百名今按照兵数应派都司守备各一员千总三员把总六员其管理粮务查玛纳斯与罗克伦相近可令该处巡检兼办晶河等处派员办理以范时绶驻札三屯之中往来巡察其驻防玛纳斯库尔喀喇乌苏由乌鲁木齐派索伦兵各六十名晶河由伊犁派索伦兵五十名屯田兵三人给马二匹驻防官兵之马共需八百四十馀匹驮载口粮籽种军器农具需驼一千三百馀只恐有不足又制车一百辆以所换哈萨克马匹挽运所有官兵盐菜银两玛纳斯等处由乌鲁木齐支领晶河由伊犁支领奏入得
旨军机大臣议奏寻议臣等前议来年在玛纳斯等处屯田酌派官兵及就近由伊犁乌鲁木齐分办口粮籽种令范时绶驻札办事今安泰等所奏派出屯田管粮各官及应行派办驻防官兵马驼诸务俱系按照情形应如所奏办理奏入
上从之

# 四、《平定准噶尔方略续编》卷十六（乾隆二十七年三月己未）"命奖赏玛纳斯等处屯田官兵"
#     ——晶河（精河）三屯屯田兵到屯、水土滋润、三月前后播种；此时范时绶已去任，委阿思哈办理三屯事务
#     （四库全书本原文，据维基文库续编卷十六；无新式标点）
# ────────────────────────────────────────────────────────────────────────

命奖赏玛纳斯等处屯田官兵以原任巡抚阿思哈驻札办事
上谕军机大臣曰旌额理等奏称从乌鲁木齐办给玛纳斯库尔喀喇乌苏晶河屯田兵丁马匹粮饷俱全抵各该处现在水土滋润三月前后可尽行播种等语此次派往屯田兵丁冲寒行走照管车辆驮载奋勉可嘉著旌额理等酌量奖赏以示鼓励玛纳斯等处既编设村庄应驻大员总办乌鲁木齐已有旌额理永徳著阿思哈即驻札库尔喀喇乌苏办理三屯事务俱著传谕知之
